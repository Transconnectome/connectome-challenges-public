# EEG 합성 데이터

[EEG 챌린지](../eeg.md)에 쓰는 **연습용 합성 뇌파**를 만드는 코드와 예제 노트북입니다. 실제 사람의 뇌파가 아니며, 눈 깜빡임과 좌우 눈 움직임이 언제 들어갔는지 정답이 함께 기록됩니다.

## 들어 있는 파일

| 파일 | 내용 |
| --- | --- |
| `generate_synthetic_eeg.py` | 합성 뇌파를 만드는 프로그램 |
| `eeg_synth.py` | 생성에 쓰는 함수 모음 |
| `eeg_synthetic_example.ipynb` | 예제 노트북: 신호 그리기 → 큰 파형 찾기 → 두피 분포 → 좌우 눈 움직임 → 정답 비교 |
| `requirements.txt` | 필요한 패키지 |

## 만들기

설치는 [시작 안내](../../START_HERE.md#4-설치와-첫-실행-30분-안팎)를 따릅니다. 이 폴더에서:

```bash
python generate_synthetic_eeg.py                         # data/ 에 생성, 몇 초
python generate_synthetic_eeg.py --seed 7 --out data_seed7   # 다른 데이터
```

같은 seed로 만들면 항상 같은 데이터가 나옵니다. `--duration`으로 길이(초)를 바꿀 수 있습니다.

| 만들어지는 파일 | 내용 |
| --- | --- |
| `data/eeg_raw.fif` | 19채널(국제 10-20 배치), 1초에 250번 측정, 3분. 모든 채널의 평균을 기준으로 한 전압. `mne.io.read_raw_fif`로 읽습니다. |
| `data/ground_truth.json` | 눈 깜빡임 정점 시각·크기, 좌우 눈 움직임 구간·방향. 분석을 마친 뒤 엽니다. |

## 어떻게 만들어지나요?

1. **배경 뇌파**: 주파수가 높을수록 세기가 약해지는 잡음(1/f 잡음)에, 뒤통수 쪽에서 강한 10 Hz 근처의 리듬(알파파)을 더합니다. 채널끼리는 가까울수록 비슷하게 움직이도록 상관을 줍니다.
2. **눈 깜빡임**: 이마 채널에서 가장 크고 뒤로 갈수록 작아지는 파형을 1분에 15회 정도 넣습니다.
3. **좌우 눈 움직임(함정)**: 눈 양옆 채널(F7, F8)에 부호가 반대인 계단 모양 신호를 넣습니다. 큰 신호를 무조건 깜빡임으로 세면 틀리게 됩니다.

## 한계

- 알파 리듬이 하나뿐입니다. 베타 리듬(약 20–25 Hz)이나 수면 중 리듬은 없습니다.
- 배경 뇌파의 성질이 시간에 따라 변하지 않습니다. 실제 뇌파처럼 알파가 커졌다 작아지거나 졸음으로 상태가 바뀌지 않습니다.
- 좌우 눈 움직임은 깜빡임과 겹치지 않게 넣으므로 실제보다 적고 규칙적입니다.
- 근육 잡음, 전극 접촉 불량 같은 다른 아티팩트는 없습니다.
- 이 데이터에서 잘 되는 방법이 실제 기록에서도 그대로 잘 된다고 가정하지 마세요.
- 설치와 실행은 macOS(Apple 칩, Python 3.11)와 Linux ARM64(Python 3.12, MNE 1.13)에서 확인했습니다. 다른 버전에서는 숫자가 조금 다를 수 있습니다.
