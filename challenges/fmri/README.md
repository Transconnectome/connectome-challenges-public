# fMRI 합성 데이터

[fMRI 챌린지](../fmri.md)에 쓰는 **연습용 합성 fMRI**를 만드는 코드와 예제 노트북입니다. 실제 사람의 뇌 영상이 아니며, 세 영역 A·B·C의 관계를 만든 사람이 정답으로 알고 있습니다.

## 들어 있는 파일

| 파일 | 내용 |
| --- | --- |
| `generate_synthetic_fmri.py` | [BrainIAK fmrisim](https://brainiak.org/docs/brainiak.utils.html#module-brainiak.utils.fmrisim)으로 4D fMRI 영상을 만들고 머리 움직임을 더하는 프로그램 |
| `fmri_synthetic_example.ipynb` | 예제 노트북: 영역별 시계열 → 상관계수 → 움직임 확인 → 움직임 시점 제거 → 정답 비교 |
| `fmri_real_data.ipynb` | 실제 공개 데이터 노트북: 같은 분석을 nilearn이 내려받는 OpenNeuro ds000228 전처리본(4명)에 적용. [챌린지 안내](../fmri.md#실제-공개-데이터로-확인하기) 참고 |
| `requirements.txt` | 필요한 패키지 |

## 만들기

설치는 [시작 안내](../../START_HERE.md#4-설치와-첫-실행-30분-안팎)를 따릅니다. 이 폴더에서:

```bash
python generate_synthetic_fmri.py                           # data/ 에 생성, 20초 안팎
python generate_synthetic_fmri.py --seed 7 --out data_seed7   # 다른 데이터
```

생성 중에 `EstimationWarning` 경고가 수백 줄 나올 수 있습니다. 마지막 줄에는 정답 상관계수가 나옵니다. 미리 보고 싶지 않다면 "저장 위치" 줄이 나왔는지만 확인하세요. 같은 seed로 만들면 항상 같은 데이터가 나옵니다. `data/`는 약 22 MB입니다.

| 만들어지는 파일 | 내용 |
| --- | --- |
| `data/bold.nii.gz` | 4D 영상 32×38×32 복셀(한 변 약 6 mm) × 200 시점, 2초마다 한 번 촬영(총 400초). 표준 뇌 공간에 맞춰 정렬되어 있지 않습니다. |
| `data/rois.nii.gz` | 영역 표시: 0=배경, 1=A, 2=B, 3=C. 각 영역은 반지름 2복셀인 공 모양(33복셀)이며 해부학적 이름은 없습니다. |
| `data/confounds.tsv` | `framewise_displacement`: 시점별 머리 움직임 크기(mm) |
| `data/ground_truth.json` | 정답 상관계수, 움직임을 넣은 시점, 생성 설정. 분석을 마친 뒤 엽니다. |

## 어떻게 만들어지나요?

1. **신경 신호**: A와 B는 같은 신호를 일부 공유하고, C는 따로 움직이는 느린 신호를 만듭니다.
2. **혈류 반응**: 신경 활동 뒤 몇 초에 걸쳐 혈류가 늘었다 줄어드는 반응 모양(HRF)을 적용해 fMRI 신호로 바꿉니다. 이때의 상관계수가 정답입니다.
3. **잡음**: fmrisim이 느린 흐름(drift), 시점 간 자기상관, 호흡·심박 같은 생리 잡음, 이웃 복셀끼리 비슷한 공간 잡음을 만듭니다.
4. **머리 움직임**: 10개 시점에 큰 움직임을 넣습니다. 그 시점과 다음 시점에 뇌 전체 신호가 함께 흔들려, 관계없는 영역 사이에도 가짜 상관이 생깁니다.

## 크기와 시간

`--voxel-mm 3`이면 64×76×64로 데이터가 약 8배 커지고, `--n-volumes`로 시점 수를 바꿀 수 있습니다. 생성에 필요한 메모리는 데이터 크기의 약 15배입니다. 기본 크기(데이터 0.03 GB)는 메모리 약 1 GB면 되고, `--voxel-mm 3 --n-volumes 800`(데이터 1 GB)은 약 15 GB가 필요합니다.

## 한계

- 실제 뇌 영상이 아니므로 움직임 보정, 정합, 표준 공간 변환 같은 공간 전처리는 연습할 수 없습니다.
- 머리 움직임은 "뇌 전체 신호가 함께 변하는" 단순한 모형입니다. 실제 움직임 아티팩트는 위치마다 다르게 나타납니다.
- 시점 수가 200개뿐이고 잡음이 있으므로, 움직임을 빼도 상관계수가 정답과 정확히 같아지지는 않습니다.
- 이 데이터에서 잘 되는 방법이 실제 영상에서도 그대로 잘 된다고 가정하지 마세요.
- 설치와 실행은 macOS(Apple 칩, Python 3.11)와 Linux ARM64(Python 3.12, brainiak 0.12)에서 확인했습니다. 다른 버전에서는 숫자가 조금 다를 수 있습니다.
