# ROCF VLM 코드북 및 용어 사전

이 문서는 [ROCF VLM 챌린지 본문](../rocf_vlm.md)과 [합성 데이터 안내](README.md)의 상세 부록입니다. 챌린지 폴더의 파일 구조, 모든 입력·출력 데이터 열(column) 정의, 실행 인자 규격, 그리고 입문자를 위한 핵심 기술·의학 용어를 정리했습니다.

### 1.2 `data.zip` 압축 해제 후 `data/` 폴더 구조 (`N=400`)

`python -m zipfile -e data.zip .`를 실행하면 전체 400명이 70/30 비율(`train` 280명, `test` 120명)로 층화 분할된 다음 파일들이 풀립니다.

| 경로 | 행·크기 | 접근 구분 (`train` vs `test`) | 설명 |
| --- | --- | --- | --- |
| `data/participants.csv` | 400행 × 2열 | `train`·`test` 모두 포함 | 참가자 ID와 `split` 분할 정보 |
| `data/train_privileged.csv` | 280행 × 16열 | **`train` 280명만 포함 (`test` 0행)** | 학습 전용 아밀로이드·임상·채점·뇌영상 지표 |
| `data/images/{subject_id}_copy.png`, `_recall.png` | 800장 (`672×480`) | `train`·`test` 모두 제공 | 모사(`copy`) 및 지연 회상(`recall`) 완성 흑백 그림 |
| `data/strokes/{subject_id}_copy.csv`, `_recall.csv` | 800개 (5 Hz) | `train`·`test` 모두 제공 | 초당 5회(0.20초 간격) 펜 좌표 및 접촉 상태 시계열 |

평가(`test`) 참가자 120명의 아밀로이드 정답과 진단군은 공개 데이터에 포함되어 있지 않으며, 모델 성능 검증은 `train` 280명 내부 교차검증과 자체 대조 검증으로 수행합니다.

## 2. CLI 명령 및 실행 제약

### 2.1 공개 CLI 인자

- **데이터 압축 해제**
  - `python -m zipfile -e data.zip .`: 현재 폴더 아래 `data/`에 제공 합성 데이터를 풉니다.
- **파이프라인 실행 (`starter_pipeline.py`, `run_pipeline.py`)**
  - `--data-dir <path>`: 입력 데이터 폴더 경로 (기본값 `data`).
  - `--out-dir <path>`: `predictions.csv`와 `summary.json`을 저장할 출력 폴더 경로.
  - `--device {cpu,cuda}`: 연산 장치 선택 (기본값 `cpu`).
  - `--seed <int>`: 파이프라인 내부 학습·교차검증 난수 시드 (기본값 `42`).
- **규격 자동 점검 (`smoke_test.py`)**
  - `--pipeline <path>`: 점검할 파이프라인 파일 경로 (기본값: 현재 폴더의 `run_pipeline.py`, 없으면 `starter_pipeline.py`).
  - `--data-dir <path>`: 입력 데이터 폴더 또는 `data.zip` 경로 (기본값: 현재 폴더의 `data/` 또는 `data.zip` 자동 탐색).
  - `--device {cpu,cuda}`: 점검 시 전달할 장치 옵션 (기본값 `cpu`).
  - `--seed <int>`: 점검용 축소 코호트 추출 및 실행 시드 (기본값 `123`).
  - `--keep`: 점검 후 임시 작업 폴더를 삭제하지 않고 남깁니다.

### 2.2 실행 및 보안 제약

- **오프라인 단독 실행**: 최종 `run_pipeline.py`는 `OPENROUTER_API_KEY=""` 환경에서 외부 네트워크 연결 없이 끝까지 실행되어야 합니다.
- **사전 학습 가중치 반입 금지**: `.pt`, `.pth`, `.safetensors`, `.ckpt`, `.onnx`, `.bin`, `.pkl`, `.joblib` 등 외부에서 미리 학습해 직렬화한 가중치·모델 파일을 저장소에 포함하거나 불러올 수 없습니다. 모든 모델은 `--data-dir`의 `train` 데이터로만 학습해야 합니다.
- **자원 및 시간 상한**: `N=400` 기준 600초 미만(노트북 CPU 120초 이내 권장), GPU 사용 시 VRAM 16 GB 이하(무료 Google Colab T4 기준)에서 동작해야 합니다.

| 열 이름 | 자료형 | 허용 값 / 예시 | 설명 |
| --- | --- | --- | --- |
| `subject_id` | `str` | `sub-0001` .. `sub-0400` | 참가자 고유 식별자 |
| `split` | `str` | `"train"`, `"test"` | 학습(280명)과 평가(120명) 분할 구분 |

### 3.3 `images/{subject_id}_{copy,recall}.png`

- **형식**: `672 × 480` 해상도의 8-bit grayscale (`PIL` `"L"` 모드) PNG 파일입니다.
- **좌표 대응**: `210.0 × 150.0 mm` 디지털 태블릿 캔버스를 그대로 투영한 완성 그림이며, 펜 잉크 밝기는 어두운 회색(`30` 안팎), 기본 종이 배경은 밝은 흰색(`255` 안팎)입니다. 배경 밝기가 조금 어두운 입력에도 견디도록 고정 임계값(예: `200`) 대신 95백분위 배경 추정치 기반의 적응 임계값을 사용하는 편이 안정적입니다.

### 3.4 `strokes/{subject_id}_{copy,recall}.csv` (4개 열, 5 Hz 시계열)

| 열 이름 | 자료형 | 단위 / 허용 값 | 설명 |
| --- | --- | --- | --- |
| `t_sec` | `float` | 초 (`s`), `>= 0.00` | 시작 시점 기준 경과 시간 (5.0 Hz, `0.20`초 간격, 소수 둘째 자리) |
| `x_mm` | `float` | `mm`, `[0.00, 210.00]` | 태블릿 가로 좌표 |
| `y_mm` | `float` | `mm`, `[0.00, 150.00]` | 태블릿 세로 좌표 |
| `pen_down` | `int` | `0` 또는 `1` | `1`: 펜이 종이에 닿아 선을 긋는 상태, `0`: 펜을 들고 이동하거나 멈춰 계획하는 상태 |

- **Osterrieth 18개 도형 구성 요소 계층**:
  - **1단계 골격(Tier 0, 단위 `2, 3, 4, 5`)**: 큰 중심 직사각형, 대각선 X자, 가로·세로 중심선
  - **2단계 이차 구조(Tier 1, 단위 `1, 13, 16, 17, 18`)**: 좌측 외곽 십자, 우측 이등변삼각형 외곽·중심선, 하단 십자, 좌하단 정사각형+대각선
  - **3단계 세부 요소(Tier 2, 단위 `6–12, 14, 15`)**: 좌측 내부 사각형·평행선 4개, 우상단 삼각형·수직선·원(점 3개), 우하단 눈금 5개, 우측 마름모·수직선 등

## 4. 제출 출력 규격 (`--out-dir`)

파이프라인 실행이 끝나면 지정한 출력 폴더(`--out-dir`)에 아래 두 파일을 저장해야 합니다.

### 4.1 `predictions.csv`

- **열 구성**: 정확히 `subject_id`, `y_prob` 2개 열만 포함합니다.
- **행과 값 제약**:
  - `participants.csv`에서 `split == "test"`인 참가자 전원을 중복이나 누락 없이 포함해야 합니다.
  - `y_prob`는 아밀로이드 베타 양성 예측 확률로, 모든 값이 유한한 실수이며 `0.0 <= y_prob <= 1.0` 범위에 있어야 합니다(`NaN`, `inf` 금지).

### 4.2 `summary.json`

- **필수 키 2개**:
  - `claim_signal` (`bool`, `true` 또는 `false`): 자체 검증을 거친 결과, 모델이 평가 데이터에서 신뢰할 만한 과정 기반 아밀로이드 신호를 포착했다고 판정하는지 나타내는 불리언 값입니다. (`starter_pipeline.py`는 정적 기준선이므로 `false`를 출력합니다.)
  - `method_summary` (`str`, 비어 있지 않은 문자열): 사용한 특징, 학습 전략, 자체 반증·검증 논리를 요약한 설명 문자열입니다.
- **선택 확장 키**: 교차검증 AUROC, 95% 신뢰구간, 자체 검증 지표, `device_used` 등 추가 진단 키를 자유롭게 함께 기록할 수 있습니다.

## 5. 핵심 기술 개념 및 입문자용 용어 사전

- **ROCF**(Rey–Osterrieth Complex Figure, 레이-오스테리에트 복합도형 검사): 복잡한 기하 도형(18개 요소, 각 0–2점, 만점 36점)을 보고 따라 그리는 **모사**(Copy)와 도형 없이 잠시 뒤 다시 그리는 **지연 회상**(Delayed Recall)으로 시공간 구성 능력과 시각 기억력을 평가하는 신경심리검사입니다.
- **아밀로이드 베타**(Amyloid-beta)와 **PET 검사**: 아밀로이드 베타는 알츠하이머병의 대표적인 병리 단백질로, 임상 증상이 뚜렷해지기 전부터 뇌에 서서히 축적될 수 있습니다. 아밀로이드 **PET**(양전자단층촬영)는 방사성 추적자를 정맥에 주사해 뇌 속 축적을 영상으로 확인하는 표준 검사이지만 비용이 비싸고 침습적입니다.
- **Centiloid**: 서로 다른 PET 영상 장비·추적자 기준에서 나온 아밀로이드 축적량을 0–100 안팎의 공통 척도로 표준화한 연속 수치입니다. 이 데이터에서는 대략 25 CL 부근을 양성 경계로 둡니다.
- **해마 평균확산도**(`hippocampal_md`)와 **설전부 평균확산도**(`precuneus_md`): 확산강조 MRI(dMRI)로 물 분자의 미세한 확산 움직임을 측정한 지표입니다. 뇌 조직이 눈으로 보일 만큼 크게 줄어들기 전의 조기 미세구조 변화를 반영할 수 있습니다.
- **해마 부피**(`hippocampal_vol`), **내후각·두정엽 피질 두께**(`entorhinal_thickness`, `parietal_thickness`), **백질 고신호 부피**(`wmh_vol_log`): 구조 MRI에서 측정하는 거시 뇌 위축 지표와 뇌 소혈관 변화 지표입니다. 해마 부피와 피질 두께 감소는 연령이나 경도인지장애와 강하게 연관되며, 백질 고신호 증가는 혈관성 운동 감속과 연관될 수 있습니다.
- **인지정상**(`CU`) / **경도인지장애**(`MCI`): `CU`(Cognitively Unimpaired)는 객관적 인지 기능이 정상 범위인 집단, `MCI`(Mild Cognitive Impairment)는 일상생활은 대체로 유지되지만 객관적인 기억·인지 저하가 시작된 집단입니다.
- **APOE4**(`apoe4_count`): 알츠하이머병의 유전적 위험 인자로 알려진 *APOE* ε4 대립유전자의 보유 개수(`0`, `1`, `2`)입니다.
- **특권 정보 활용 학습**(Learning Using Privileged Information): 모델을 훈련할 때(`train`)는 MRI 뇌지표나 임상 정보 같은 풍부한 추가 데이터를 함께 활용하되, 실제 예측할 때(`test`)는 그림과 펜 궤적 같은 저비용 입력만으로 작동하도록 모델을 학습시키는 패러다임입니다. 교란 잔차화, 다중과제 학습, 표현 정렬, 지식 증류 등이 대표 전략입니다.
- **교란 변수**(Confounding)와 **천장효과**(Ceiling effect):
  - **교란 변수**는 입력과 예측 목표 양쪽에 모두 영향을 주어, 실제 인과·직접 신호가 없는데도 모델이 잘 맞히는 것처럼 착시를 만드는 제3의 변수입니다(예: 임상 진단군).
  - **천장효과**는 과제가 특정 집단에게 쉬워 점수가 만점 근처에 몰리면서, 완성 결과만으로는 그 집단 내부의 미세한 차이를 가려내기 어려워지는 현상입니다.
- **AUROC**(Area Under the ROC Curve)와 **진단군 내 층화 AUROC**·**95% 신뢰구간**:
  - **AUROC**는 양성과 음성을 가르는 판별력 지표로, `0.50`은 동전 던지기(무작위), `1.00`은 완벽한 분리를 뜻합니다.
  - **진단군 내 층화 AUROC**는 전체를 한꺼번에 섞어 재지 않고 각 임상 집단 내부에서 따로 판별력을 계산해 합산함으로써, 진단군 구성 차이에 기대는 교란 착시를 배제합니다.
  - **95% 신뢰구간**은 표본을 반복 재추출(부트스트랩)해 추정한 성능의 불확실성 범위로, 우연에 의한 흔들림을 넘는지 확인하는 데 쓰입니다.
- **VLM**(Vision-Language Model, 시각-언어 모델)과 **OpenRouter API 키**: 그림과 텍스트를 함께 이해하는 다중모달 AI 모델입니다. 개발 단계에서 그리기 과정 시각화 패널의 패턴을 탐색할 때 외부 VLM API 키를 선택적으로 쓸 수 있으나, 최종 제출 파이프라인은 API 키 없이 오프라인으로 실행되어야 합니다.
- **교차검증**(Cross-Validation), **홀드아웃**(Holdout), **자체 반증 검증**:
  - **교차검증**은 학습 데이터를 여러 조각(폴드)으로 나누어 번갈아 검증하며 일반화 성능을 재는 방법입니다.
  - **홀드아웃**은 모델 선택 과정에서 끝까지 보지 않고 따로 떼어 둔 시험 표본입니다.
  - **자체 반증 검증**은 모델이 진짜 과정 단서를 배웠는지 확인하기 위해 핵심 단서를 망가뜨리거나 무작위 조건과 비교해 거짓 양성이 나오지 않는지 스스로 시험하는 절차입니다.
