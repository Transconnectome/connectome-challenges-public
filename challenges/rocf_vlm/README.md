# ROCF VLM 합성 데이터

[ROCF VLM 챌린지](../rocf_vlm.md)에 쓰는 **사전 생성 블라인드 합성 데이터(`data.zip`)**, 시각화·평가 도우미, 정적 기준선 파이프라인, 규격 점검기, 예제 노트북입니다. 모든 열 정의와 용어 풀이는 [**코드북 (CODEBOOK.md)**](CODEBOOK.md)에 정리되어 있습니다. 실제 사람의 임상·뇌영상 기록이 아니며, 블라인드 평가(`test`) 참가자 120명의 정답은 공개되지 않습니다.

## 들어 있는 파일

| 파일 | 내용 |
| --- | --- |
| `data.zip` | 사전 생성된 합성 ROCF 코호트(`N=400`, `train` 280명 / 블라인드 `test` 120명). 압축을 풀면 `data/` 폴더가 만들어집니다. |
| `rocf_viz.py` | 5 Hz 펜 궤적 시간 색상·멈춤·진행 스냅샷 패널 렌더링(`render_process_panel`) 및 진단군 내 층화 AUROC 계산(`compute_within_dx_metrics`) 도우미 |
| `starter_pipeline.py` | 정적 흑백 그림만 사용하는 최소 기준선 (`predictions.csv`, `summary.json` 출력) |
| `smoke_test.py` | 단일 실행 규격, 사전 학습 가중치 반입 금지, 오프라인 실행, 최소 `predictions.csv`·`summary.json` 검증, `N=400` 환산 600초 이내 점검 스크립트 |
| `rocf_vlm_synthetic_example.ipynb` | 데이터 구조 확인 → 정적 그림과 그리기 과정 비교 → 학습 데이터 교차검증 예제 노트북 |
| `CODEBOOK.md` | 전체 파일 구조, 모든 CSV·JSON 열 명세(16개 학습 전용 열 포함), 입문자용 용어 사전 |
| `requirements.txt` | 필요한 Python 패키지 |

## 데이터 준비하기

설치는 [시작 안내](../../START_HERE.md#4-설치와-첫-실행-30분-안팎)를 따릅니다. 이 폴더에서 아래 명령으로 제공된 압축 파일의 압축을 풉니다.

```bash
python -m zipfile -e data.zip .
```

압축을 풀면 현재 폴더 아래에 `data/` 디렉터리가 만들어집니다(`.gitignore`에 `data/`가 포함되어 있으므로 압축을 푼 1,600여 개 개별 파일은 Git에 올라가지 않습니다). 실제 평가 환경에서는 이미지 배경 밝기·펜 궤적 미세 잡음이나 표형 열 결측치(`NaN`)가 달라질 수 있으므로, 이미지 이진화에는 배경 추정 기반 적응 임계값을, 특권 표 처리에는 결측치 대치(예: 중앙값 대치)를 함께 적용하는 편이 안전합니다.

| 압축 해제 후 파일 | 내용 |
| --- | --- |
| `data/participants.csv` | 참가자 `N=400`명의 분할 표(`train` 280명 / `test` 120명 층화 분할). 평가 시점에 ROCF 그림·과정 외의 외부 변수를 읽을 수 없도록 구조적으로 분리되어 있습니다. |
| `data/train_privileged.csv` | **`train` 280명 전용** 16개 열 특권 정보 표 (`test` 행은 전혀 포함되지 않음; 전체 열 정의는 [CODEBOOK.md](CODEBOOK.md) 참고). |
| `data/images/` | 참가자별 모사·지연 회상 완성 정적 흑백 이미지(`672×480` 8-bit grayscale). 그리기 순서나 펜을 들고 멈춘 시간 정보는 들어 있지 않습니다. |
| `data/strokes/` | 참가자별 5 Hz(0.20초 간격) 디지털 펜 시계열 파일(`210.0×150.0 mm` 캔버스 좌표, 접촉·들림 상태 포함). |

| 데이터 구분 | `train` (학습용, 280명) | `test` (평가용, 120명) |
| --- | --- | --- |
| `images/` + `strokes/` | 제공 (학습 입력 가능) | 제공 (추론 입력) |
| `train_privileged.csv` (16개 열) | **280행 제공** | **0행 (미포함)** |
| 정답 라벨 (`amyloid_pos`) | `train_privileged.csv`에 포함 | **비공개 (블라인드 평가)** |

## 데이터 구성 특성

1. **임상 집단과 아밀로이드 부하**: 참가자 `N=400`명의 인구통계, 유전 위험 인자, 임상 진단군(인지정상·경도인지장애), 아밀로이드 베타 양성 여부와 연속 척도 수치가 반영되어 있습니다. 임상 집단 구성에 따라 아밀로이드 양성 비율과 정적 도형 완성도가 함께 달라져 교란이 생길 수 있습니다.
2. **정적 그림의 천장효과**: 인지정상 집단은 대부분 높은 점수대에 모여 완성된 정적 그림만으로는 집단 내부 차이를 가려내기 어렵습니다.
3. **5 Hz 시공간 그리기 과정 신호와 학습 전용 뇌지표**: 완성된 도형이 비슷해 보이더라도 아밀로이드 병리가 높을수록 펜을 들고 멈추는 구간이나 모사 대비 지연 회상에서의 순서 구성에 변화가 생길 수 있으며, 학습 전용 표에 포함된 조기 미세구조 확산 지표·거시 뇌 위축 지표·혈관성 변화 지표가 각기 다른 생물학적 단서와 잡음을 담고 있습니다.

## 한계

- 18개 ROCF 구성 요소를 규칙 기반 선분·기하 도형으로 합성했으므로, 실제 사람의 자유로운 손글씨·곡선 비대칭·종이 기울임·필압 및 펜 기울기 변화는 반영되어 있지 않습니다.
- 학습 전용 표의 뇌영상 지표(해마·설전부 미세구조, 뇌 부피 및 피질 두께 등)는 실제 MRI/PET 측정값이 아니라 특권 정보 활용 학습(Learning Using Privileged Information)·교란 제거 학습을 연습하기 위해 문헌 경향만 단순화해 생성한 합성 표입니다.
- 이 합성 데이터에서 높은 점수를 낸 특징이나 임계값을 실제 임상 집단에 그대로 적용해서는 안 됩니다. 기본 파이프라인과 노트북은 Python 3.11·3.12 환경(일반 노트북 CPU 및 무료 Google Colab T4 GPU 호환)을 기준으로 작성되었습니다.
