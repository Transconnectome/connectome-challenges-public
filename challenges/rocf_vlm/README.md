# ROCF VLM 합성 데이터

[ROCF VLM 챌린지](../rocf_vlm.md)에 쓰는 **연습·검증용 합성 디지털 펜 기록과 학습 전용 뇌지표**를 만드는 코드, 정적 기준선 파이프라인, 규격 검증기, 예제 노트북입니다. 모든 열 정의와 용어 풀이는 [**코드북 (CODEBOOK.md)**](CODEBOOK.md)에 정리되어 있습니다. 실제 사람의 임상·뇌영상 기록이 아니며, 블라인드 테스트 정답과 생성 설정이 `data/ground_truth.json`에 따로 저장됩니다.

## 들어 있는 파일

| 파일 | 내용 |
| --- | --- |
| `rocf_synth.py` | 18개 ROCF 도형 요소 기하 정의, 5 Hz 펜 궤적·학습 전용 뇌지표 생성, 정적 흑백 이미지·과정 진행 패널 렌더링 및 평가 유틸리티 모음 |
| `generate_synthetic_rocf.py` | 참가자 분할 표, 학습 전용 뇌·임상 특권 표, `Copy`·`Delayed Recall` 그림 및 5 Hz 펜 기록 생성 프로그램 (`--seed`, `--n-subjects`, `--out` 지원) |
| `starter_pipeline.py` | 정적 흑백 그림 기반 최소 기준선 (`predictions.csv`, `summary.json` 출력) |
| `smoke_test.py` | 단일 실행 규격, 사전 학습 가중치 반입 금지, 오프라인 실행, 최소 `predictions.csv`·`summary.json` 검증, `N=400` 환산 600초 이내 점검 스크립트 |
| `rocf_vlm_synthetic_example.ipynb` | 데이터 구조 확인 → 정적 그림과 그리기 과정 비교 → 학습 전용 뇌지표 탐색 → 기준선 동작 확인 예제 노트북 |
| `CODEBOOK.md` | 전체 파일 구조, 모든 CSV·JSON 열 명세(16개 학습 전용 열 포함), 입문자용 용어 사전 |
| `requirements.txt` | 필요한 Python 패키지 |

## 만들기

설치는 [시작 안내](../../START_HERE.md#4-설치와-첫-실행-30분-안팎)를 따릅니다. 이 폴더에서 아래 명령을 실행합니다.

```bash
python generate_synthetic_rocf.py                           # data/ 에 기본 데이터(seed 42) 생성
python generate_synthetic_rocf.py --seed 7 --out data_seed7 # 다른 난수(seed 7) 데이터 생성
```

같은 `--seed`를 주면 항상 같은 데이터가 만들어집니다. 실제 환경에서는 이미지 배경 밝기·펜 궤적 미세 잡음이나 표형 열 결측치(`NaN`)가 달라질 수 있으므로, 이미지 이진화에는 배경 추정 기반 적응 임계값을, 특권 표 처리에는 결측치 대치(예: 중앙값 대치)를 함께 적용하는 편이 안전합니다.

| 만들어지는 파일 | 내용 |
| --- | --- |
| `data/participants.csv` | 참가자 `N=400`명의 분할 표(`train` 280명 / `test` 120명 층화 분할). 평가 시점에 ROCF 그림·과정 외의 외부 변수를 읽을 수 없도록 구조적으로 분리합니다. |
| `data/train_privileged.csv` | **`train` 280명 전용** 16개 열 특권 정보 표 (`test` 행은 전혀 포함되지 않음; 전체 열 정의는 [CODEBOOK.md](CODEBOOK.md) 참고). |
| `data/images/` | 참가자별 모사·지연 회상 완성 정적 흑백 이미지(`672×480` 8-bit grayscale). 그리기 순서나 펜을 들고 멈춘 시간 정보는 들어 있지 않습니다. |
| `data/strokes/` | 참가자별 5 Hz(0.20초 간격) 디지털 펜 시계열 파일(`210.0×150.0 mm` 캔버스 좌표, 접촉·들림 상태 포함). |
| `data/ground_truth.json` | 블라인드 `test` 120명의 정답·진단·참고 지표. 파이프라인 코드에서는 절대 읽지 않으며 모든 모델링과 자체 검증을 마친 뒤 사후 확인에만 사용합니다. |

| 데이터 구분 | `train` (학습용, 280명) | `test` (평가용, 120명) |
| --- | --- | --- |
| `images/` + `strokes/` | 제공 (학습 입력 가능) | 제공 (추론 입력) |
| `train_privileged.csv` (16개 열) | **280행 제공** | **0행 (미포함)** |
| `ground_truth.json` | 미포함 | 블라인드 정답 (**파이프라인에서 읽기 금지**) |

## 어떻게 만들어지나요?

1. **임상 집단과 아밀로이드 부하 생성**: 참가자 `N=400`명의 인구통계, 유전 위험 인자, 임상 진단군(인지정상·경도인지장애), 아밀로이드 베타 양성 여부와 연속 척도 수치를 생성합니다. 임상 집단 구성에 따라 아밀로이드 양성 비율과 정적 도형 완성도가 함께 달라져 교란이 생길 수 있도록 설계했습니다.
2. **정적 그림의 천장효과**: 인지정상 집단은 대부분 높은 점수대에 모여 완성된 정적 그림만으로는 내부 차이를 가려내기 어렵도록 구성했습니다.
3. **5 Hz 시공간 그리기 과정 신호와 학습 전용 뇌지표**: 완성된 도형이 비슷해 보이더라도 아밀로이드 병리가 높을수록 펜을 들고 멈추는 구간이나 모사 대비 지연 회상에서의 순서 구성에 변화가 생기며, 학습 전용 표에 포함된 조기 미세구조 확산 지표·거시 뇌 위축 지표·혈관성 변화 지표가 각기 다른 생물학적 단서와 잡음을 반영하도록 만들었습니다.

## 한계

- 18개 ROCF 구성 요소를 규칙 기반 선분·기하 도형으로 합성했으므로, 실제 사람의 자유로운 손글씨·곡선 비대칭·종이 기울임·필압 및 펜 기울기 변화는 반영되어 있지 않습니다.
- 학습 전용 표의 뇌영상 지표(해마·설전부 미세구조, 뇌 부피 및 피질 두께 등)는 실제 MRI/PET 측정값이 아니라 특권 정보 활용 학습(Learning Using Privileged Information)·교란 제거 학습을 연습하기 위해 문헌 경향만 단순화해 생성한 합성 표입니다.
- 실제 신경심리검사에서는 숙련된 평가자가 모호한 선 연결이나 비율 왜곡을 채점 지침에 따라 판정하지만, 합성 데이터는 생성 모형의 요소 점수를 직접 기록합니다.
- 이 합성 데이터에서 높은 점수를 낸 특징이나 임계값을 실제 임상 집단에 그대로 적용해서는 안 됩니다. 기본 파이프라인과 노트북은 Python 3.11·3.12 환경(일반 노트북 CPU 및 무료 Google Colab T4 GPU 호환)을 기준으로 작성되었습니다.
